## ДЕНЬ 50: Explaining Code (Walkthrough)

### Навчальні цілі дня:
- Проводити Code Walkthrough
- Signposting words

### LESSON 50.1: The Structure (20 хвилин)
**Context -> Input -> Logic -> Output.**
"This function validates the user. It takes the email string. First, it checks the regex. Then it queries the DB. Finally, it returns a boolean."

### LESSON 50.2: Signposting (15 хвилин)
- **First of all...**
- **Next...**
- **Then...**
- **Finally...**

---

## ДЕНЬ 51: Debugging Narratives

### Навчальні цілі дня:
- "Tell me about a bug you fixed"
- Cause & Effect

### LESSON 51.1: The Detective Story (20 хвилин)
1.  **Symptom:** "The app crashed on login."
2.  **Hypothesis:** "I suspected a race condition."
3.  **Test:** "I reproduced it by spanning requests."
4.  **Fix:** "I added a mutex lock."

### LESSON 51.2: Grammar - Cause/Effect (15 хвилин)
- "**Due to** high load..."
- "**Because** the index was missing..."
- "This **resulted in** a timeout."

---

## ДЕНЬ 52: Discussing Trade-offs

### Навчальні цілі дня:
- Pros vs Cons
- Decision making vocabulary

### LESSON 52.1: The Senior Perspective (20 хвилин)
There is no "best" solution, only trade-offs.
"We chose Monolith over Microservices because our team is small (**Con** is scalability, **Pro** is speed of iteration)."
**Vocabulary:**
- **Scalability vs Complexity**
- **Time vs Space**
- **Long-term vs Short-term**

---

## ДЕНЬ 53: System Design Basics (English)

### Навчальні цілі дня:
- Vocabulary for System Design
- Describing Diagrams

### LESSON 53.1: Design Vocabulary (20 хвилин)
- **Load Balancer**: Distributes traffic.
- **Cache**: Stores hot data.
- **Queue**: Asynchronous processing.
- **Bottleneck**: The slow part.
- **Single Point of Failure**: The risky part.

---

## ДЕНЬ 54: Whiteboard Coding Explanation

### Навчальні цілі дня:
- "Coding Live" comments
- Filler words for thinking

### LESSON 54.1: Thinking Aloud (20 хвилин)
Don't be silent while coding on a whiteboard.
- "I'm thinking about using a HashMap here to optimize lookup."
- "Let me handle the edge case where the array is empty."
- "This approach is O(n) time complexity."
