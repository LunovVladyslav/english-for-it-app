## ДЕНЬ 141: What makes a good README?

### Навчальні цілі дня:
- Understanding structure
- User-centric writing

### LESSON 141.1: The 'First Impression' (20 хвилин)
Your README is the face of your project.
**Must-haves:**
1.  **Title & One-liner:** What is it?
2.  **Installation:** How to run it?
3.  **Usage:** How to use it?

---

## ДЕНЬ 142: Instructional Language (Imperatives)

### Навчальні цілі дня:
- Giving Instructions
- Imperative Goal

### LESSON 142.1: Be Bossy (Politely) (20 хвилин)
In technical instructions, use the base verb (Imperative).
- ✅ "**Click** the button." (Not "You should click").
- ✅ "**Run** the script."
- ✅ "**Copy** the config."

---

## ДЕНЬ 143: Formatting with Markdown

### Навчальні цілі дня:
- Visual Hierarchy
- Code blocks

### LESSON 143.1: Make it Scannable (15 хвилин)
- Use Headers (`#`, `##`) for sections.
- Use `Code` ticks for technical terms.
- Use Triple Ticks (```) for blocks.

---

## ДЕНЬ 144: Installation Guides

### Навчальні цілі дня:
- Step-by-step clarity
- Prerequisites

### LESSON 144.1: The Happy Path (20 хвилин)
1.  **Prerequisites:** Node.js > 14.
2.  **Clone:** `git clone ...`
3.  **Install:** `npm install`
4.  **Run:** `npm start`

---

## ДЕНЬ 145: Troubleshooting Sections

### Навчальні цілі дня:
- Problem-Solution format
- Anticipating error

### LESSON 145.1: The FAQ (20 хвилин)
**Format:** Q: Problem? A: Solution.
Q: "I get EADDRINUSE error."
A: "Kill the process on port 3000."
