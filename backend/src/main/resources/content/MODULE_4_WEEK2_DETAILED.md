## ДЕНЬ 92: The SBI Model

### Навчальні цілі дня:
- Giving constructive feedback
- Situation-Behavior-Impact

### LESSON 92.1: The Framework (20 хвилин)
Don't say "You were rude."
Say: "In the meeting (**Situation**), when you interrupted me (**Behavior**), it made me feel unheard (**Impact**)."

---

## ДЕНЬ 93: Positive Feedback (Praise)

### Навчальні цілі дня:
- Boosting morale
- Specificity

### LESSON 93.1: Beyond "Good Job" (15 хвилин)
- "I really appreciated how you handled that client."
- "Great catch on that bug, it saved us hours."
- "Your documentation is extremely clear."

---

## ДЕНЬ 94: Developing & Softening Feedback

### Навчальні цілі дня:
- "Constructive" criticism
- Softeners

### LESSON 94.1: Softening the Blow (20 хвилин)
- "You **might want to** consider..."
- "Top focus on..."
- "One **suggestion** would be..."
- "Have you thought about...?"

---

## ДЕНЬ 95: Receiving Feedback

### Навчальні цілі дня:
- Not getting defensive
- Asking for examples

### LESSON 95.1: The Growth Mindset (20 хвилин)
- "**Thanks for the feedback.**" (Even if it hurts).
- "Could you give me an example of when I did that?"
- "How would you suggest I handle it next time?"

---

## ДЕНЬ 96: Code Review Etiquette

### Навчальні цілі дня:
- Written feedback on code
- Nit vs Blocker

### LESSON 96.1: Review Comments (20 хвилин)
- "**Nit:** Indentation here."
- "**Blocking:** This introduces a security risk."
- "**Suggestion:** Maybe extract this to a function?"
- "**Question:** What happens if this is null?"

---

## ДЕНЬ 97: Practice - The Difficult Conversation

### Task: The Underperformer
Role-play: You have to tell a colleague their code quality has dropped. Use SBI.
"Hey, I noticed in the last sprint (**S**) that 3 of your PRs had to be returned (**B**). This delayed the release (**I**)."
