## ДЕНЬ 29: The Art of Simplification (ELI5)

### Навчальні цілі дня:
- Навчитися пояснювати складне простими словами (ELI5)
- Використовувати аналогії
- Grammar: Relative Clauses

### LESSON 29.1: Why Simplification Matters (15 хвилин)

В IT ми часто говоримо з нетехнічними людьми (PMs, clients, sales).
**The Golden Rule:** "If you can't explain it simply, you don't understand it well enough."

**Strategy: The Analogy Bridge**
Поєднуйте [New Tech Concept] з [Known Real World Concept].

| Tech Concept | Analogy | Explanation |
| :--- | :--- | :--- |
| **API** | A Waiter | Takes your order (request), gives it to the kitchen (server), and brings food (response). |
| **Database** | A Library | A place to store books (data). You need an index (ID) to find them quickly. |
| **Bug** | A Typo in a recipe | The cook followed instructions, but the recipe was wrong, so the cake tastes bad. |

### LESSON 29.2: Grammar - Relative Clauses (20 хвилин)

Використовуємо `who`, `which`, `that`, `where` щоб давати визначення.

1.  **WHO (people):** "A developer is someone **who** writes code."
2.  **WHICH/THAT (things):** "Jira is a tool **which** helps us track tasks."
3.  **WHERE (places):** "Slack is a workspace **where** we communicate."

**Practice:**
*   *Git is a tool. It tracks changes.* -> "Git is a tool **that** tracks changes."

## ДЕНЬ 30: Project Overview Architecture

### Навчальні цілі дня:
- Описувати архітектуру проєкту
- Vocabulary: Frontend, Backend, Fullstack
- Grammar: Participle Clauses

### LESSON 30.1: Project Description Framework (25 хвилин)

Structure for "Tell me about your project":
1.  **The What:** "I'm working on an e-commerce platform."
2.  **The How (Stack):** "We use Java Spring Boot and React."
3.  **The Scale:** "It handles 50k requests/day."

### LESSON 30.2: Grammar - Participle Clauses (20 хвилин)

Making sentences professional and concise.

*   *Long:* "The app, **which uses** AI, provides suggestions."
*   *Short:* "The app, **using** AI, provides suggestions."
*   *Long:* "The database, **which is hosted** on Azure..."
*   *Short:* "The database, **hosted** on Azure..."

## ДЕНЬ 31: Problem-Solution Storytelling

### Навчальні цілі дня:
- Розповідати про технічні виклики
- Структура: Problem -> Solution -> Result

### LESSON 31.1: The Story Arc (20 хвилин)

**1. The Trigger (Problem):** "We noticed the login page was slow (5s)."
**2. The Investigation (Action):** "I profiled the queries and found a missing index."
**3. The Resolution (Solution):** "I added the index."
**4. The Outcome (Result):** "Load time dropped to 200ms."

**Useful Phrases:**
- "We faced a challenge with..."
- "To address this..."
- "This resulted in..."

## ДЕНЬ 32: Technology Justification

### Навчальні цілі дня:
- Пояснювати вибір технологій (Why this tool?)
- Порівняння (Comparatives)

### LESSON 32.1: The "Why" Question (20 хвилин)

Client: "Why did you choose React over Angular?"
You need to justify with **Business Value**, not just "I like it".

*   **Speed:** "React allows for faster rendering, which improves user experience."
*   **Talent:** "It's easier to find developers for React."
*   **Ecosystem:** "The library ecosystem is strictly larger."

### LESSON 32.2: Grammar - Comparatives (15 хвилин)
- "React is **more flexible than** Angular."
- "Go is **faster than** Python for this specific task."
- "This is **the most efficient** solution."

## ДЕНЬ 33: Explaining Processes & Workflows

### Навчальні цілі дня:
- Описувати процеси (CI/CD, Agile)
- Sequence words

### LESSON 33.1: The Lifecycle (20 хвилин)

Explaining how code gets to production.

"**First**, we write the code and run local tests. **Then**, we push to GitHub. **Once** the PR is approved, it deploys to Staging. **Finally**, after QA sign-off, it goes to Production."

**Vocabulary:**
- **Pipeline**: Automated steps.
- **Merge**: Combining code.
- **Rollback**: Reverting to previous version.
